# Digital Marketing Pro — موقع HTML / CSS / JS / Bootstrap 5

كل صفحة **ملف واحد فقط**، واللغة (عربي ↔ English) تتغير بالـ JavaScript بدون إعادة تحميل، والاختيار يُحفظ للصفحات التالية.
بدون Node وبدون قاعدة بيانات. الفورم يعمل بملف PHP صغير.

## الرفع
ارفع **محتويات** المجلد إلى `public_html` (أو جذر الدومين).

```
index.html about.html services.html projects.html blog.html contact.html privacy.html terms.html 404.html
services/*.html   blog/*.html
assets/ (css, js, fonts, img, video)     api/contact.php     sitemap.xml robots.txt .htaccess
```

## 1) بيانات الشركة — ملف واحد: `assets/js/config.js`
الهاتف، الواتساب، الإيميل، العنوان، ساعات العمل، روابط السوشيال (فيسبوك، إنستجرام، يوتيوب، لينكدإن، تيك توك)، أكواد التتبع، وأرقام شريط الإحصائيات (`content.stats`: 340+ عميل سعيد، 9 مشاريع تحت التنفيذ).
أيقونات السوشيال والواتساب والجوال تظهر دائمًا؛ لو الرابط لسه فاضي يظهر للزائر "سيتم إضافة هذا الرابط قريبًا"، وبمجرد ما تكتبه يشتغل مباشرة.
- الواتساب: رقم بكود الدولة بدون + (مثال `966500000000`).
- `showTestimonialPlaceholders: false` يخفي قسم آراء العملاء، و`showDemoProjects: false` يخفي المشاريع التوضيحية.

## 2) فورم التواصل
انسخ `api/config.sample.php` باسم `api/config.php` واكتب `to_email` (وممكن `webhook_url`). من غير ده الفورم يعرض خطأ صريح ولا يدّعي نجاحًا.
يتطلب استضافة تدعم PHP. الحماية: تحقق في المتصفح والسيرفر، honeypot، حد أدنى لوقت التعبئة، same-origin، حد محاولات لكل IP، منع الوصول المباشر لـ config.php.

## 3) الدومين
استبدل `https://www.YOUR-DOMAIN.com` بدومينك في كل الملفات (Find & Replace) ثم ارفع `sitemap.xml` في Search Console.

## 4) ملاحظات
- **الفيديو** `assets/video/hero*.mp4 / hero*.webm (نسخة عادية للإنجليزي ونسخة معكوسة للعربي)` (حوالي 0.5MB لكل واحد) يعرض خدمات الشركة بالرسوم المتحركة بدون نصوص، فيصلح للغتين، وفيه زر إيقاف.
- **آراء العملاء** الحالية (9 قطاعات) بأسماء مصرية افتراضية ومكتوب عليها "نموذج توضيحي". استبدلها بآراء حقيقية (بموافقة أصحابها) أو أخفِها.
- عبارة "في السوق منذ عام 2009" مكتوبة بناءً على معلومتك — تأكد منها قبل النشر.
- الخصوصية والشروط قوالب عامة وتحتاج مراجعة قانونية.
- الأيقونات: Lucide (ISC) · السوشيال: Simple Icons (CC0، ومنها يوتيوب) وFont Awesome LinkedIn (CC BY 4.0) · الخطوط: IBM Plex Sans Arabic وInter (OFL) · Bootstrap 5.3 (MIT).

## النسخة المدمجة (v3) — ما الذي أُضيف من الموقع الأول
بدون تكرار: كل ميزة موجودة في الموقعين (بريلودر، ظهور عند السكرول، العدادات، زر الأعلى، تبديل اللغة، الأسئلة الشائعة) بقيت نسخة واحدة فقط.
- **سلايدر الموشن جرافيك** في الرئيسية (3 فيديوهات + نصوص، شريط تقدم، أسهم، سحب بالإصبع، زر إيقاف، يبدأ عند الوصول إليه) — `assets/video/motion-*`
- **شريط تقدم السكرول** أعلى كل الصفحات.
- **نص "من نحن" الذي تضيء كلماته** مع السكرول.
- **تايم لاين طريقة العمل** (6 مراحل) بخط يمتلئ مع السكرول بدل البطاقات الثابتة.
- **الباقات الثلاث** (انطلاقة / نمو / ريادة) — كل زر يفتح واتساب برسالة جاهزة للباقة.
- **كاروسيل القطاعات** (سحب + أسهم).
- **شريط الأدوات المتحرك** بدل بطاقات الأدوات الثابتة (3 مسارات).
- **زر "أرسل عبر واتساب"** في فورم التواصل، ويظهر أيضًا كبديل لو فشل إرسال الفورم (مهم على GitHub Pages لأنه لا يشغّل PHP).
- أسئلة شائعة إضافية (الميزانية، متى تظهر النتائج، السعودية ومصر، ملكية الحسابات، متابعة النتائج، الموشن) + بطاقتا "سوقان نعرفهما" و"حساباتك ملكك" في قسم لماذا نحن.
- سناب شات في أيقونات السوشيال (`social.snapchat` في config.js)، والعنوان: الرياض، وإحصائيتان إضافيتان (سوقان / 24 ساعة) — عدّلها أو احذفها من `config.js`.

## تحديث v4
- **التحميل**: لوجو الشركة يظهر بتأثير تركيز ولمعة، وحوله حلقة تقدّم وأيقونات الخدمات تدور، وخلفية أورورا داكنة، ثم بوابة مضيئة تفتح على الموقع (حوالي 2.3 ثانية) في كل الصفحات. الكود: `#preloader` في الـ HTML، ودالة `initPre` في `main.js`، وقسم "Preloader" في `style.css`.
